# AI Interaction & Workflow Rules

When implementing or updating features in this showcase project:

1. **Discover via `llms.txt`:** Start by reading `node_modules/sbwb-ds-v2-aggrid/docs/llms.txt` and load `spreadsheet-mode.md`, `standard-grid.md`, and `api-reference.md` (plus `react-hook-form.md` if used).
2. **Verify `pt-BR` & Spreadsheet APIs:** Before writing code, briefly list the exact props, locale configurations, column types, and Spreadsheet module options found in the library's consumer docs.
3. **Self-Verify:** Run `npm run build` (or `tsc --noEmit`) after generating code to ensure zero TypeScript errors against the installed package types.
