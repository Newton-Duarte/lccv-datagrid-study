> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development task-by-task. The user selected orchestration with implementation delegated to GPT-5.6 Luna at xhigh. No worktrees or TDD; implement before regression checks. Steps use checkbox syntax for tracking.

**Goal:** Deliver the approved DS-based user-screen refinements, reusable controls, salary naming, and feature organization while preserving Spreadsheet behavior.

**Architecture:** Shared `AppSelect` and ISO-first `AppDatePicker` compose the public Design System independently of users, React Hook Form, and AG Grid. `src/features/users` owns domain metadata, form/baseline state, column definitions, the stable Spreadsheet adapter, and thin grid editors. Generic date/currency helpers live in `src/utils`; header, footer, Alert summary, and cell accessibility renderers remain focused components.

**Tech Stack:** Existing React 19, strict TypeScript, Vite, `@sbwb-design-system/ui-core`, `@sbwb-design-system/themes`, React Hook Form/Zod/resolver, `sbwb-ds-v2-aggrid`, public Community peers, Node test runner, and available `playwright-cli`. No new dependencies are expected.

**Spec:** `docs/superpowers/specs/2026-11-26-users-refinements-design.md` (approved).

## Global Constraints

- Keep everything in memory, in `pt-BR`, without an Actions column or backend.
- Preserve the existing execution preferences when implementation is authorized: orchestration with GPT-5.6 Luna at xhigh, no worktrees, and no TDD. Regression checks follow implementation.
- Keep the shared controls independent of users, React Hook Form, and AG Grid.
- Choosing a profile or calendar date commits the cell immediately and closes the picker. Typed dates retain Enter/Tab confirmation and Escape cancellation.
- The shared `AppDatePicker` accepts an ISO calendar-date string (`YYYY-MM-DD`) or an empty string; it converts to/from DS `Date` values internally.
- Rename `numericValue` to `salary` end-to-end, without a compatibility alias, and use `Perfil` for the final label.
- Do not change DataGrid font sizes or override AG Grid classes.
- Use DS components, available semantic/theme utilities and tokens; no app-authored hexadecimal colors in the screen or controls. Verify computed colors rather than assuming an unavailable `error-*` utility namespace exists.
- Preserve stable adapters/bindings/column IDs during edits, synchronous accepted publication and acknowledgments, and one RHF/Zod/resolver owner.
- Read current `AGENTS.md`, project context and bundled wrapper guides before grid work. Use Context7 for current peer API questions; installed DS public declarations/runtime are authoritative because Context7 has no matching DS entry.
- Commit only task-owned source/docs/checks. Reports, screenshots and tool artifacts stay ignored or under `/tmp`; never force-add `.superpowers/` reports.

## Review Focus

- Date value→empty→value and external reset: the shared picker must not resurrect a prior date or shift a day through UTC conversion (Tasks 1/2 checks).
- A portalled picker can be mistaken for an outside click: selection must commit the chosen value exactly once and restore usable grid focus (Task 2 browser cases).
- Opening a clean editor is not a change: actions remain disabled until an actual draft differs, but Save must capture the first uncommitted edit (Task 3 browser cases).
- Two unnamed/equal-name drafts must retain unique Alert IDs and accessible cell descriptions across correction, sorting and remount (Task 3 browser cases).
- Equal-valued Discard with populated history must block both undo and redo from reverting a saved value (Task 3 automated regression).
